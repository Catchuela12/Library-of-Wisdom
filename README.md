## About the Project
A collaborative Markdown-based digital encyclopedia.

The Shared Library of Wisdom is a collaborative project that simulates real-world GitHub workflows. Team members build a Markdown-based digital encyclopedia using feature branches, pull requests, and merge conflict resolution to practice proper version control and teamwork.

## Purpose
This project is designed to help students understand collaborative software development by working in a shared repository while following Git best practices.

## Workflow Overview
- Feature branch development  
- Pull request reviews  
- Merge conflict handling  
- Collaborative documentation using Markdown
